# 《光与影：33号远征队》简体中文文本修订 Mod

针对《光与影：33号远征队》（Clair Obscur: Expedition 33）官方简体中文的文本修订补丁。

官方简中整体质量不错，但仍存在错译、语义反向、机翻腔、漏译、标点错误，以及若干专有名词硬伤。本 Mod 在**不改动任何专有名词、数值与玩法的前提下**，对其中 451 处文本做了修订，并统一了少量前后不一致的术语。


## 修订内容

- 审校范围：`zh-Hans` 全部 **13,922 条**文本、**217 个命名空间**，逐条对照英文原文。
- 最终改动 **451 条**：
  - 对话与过场动画字幕（`ST_CS_*`、`ST_BD_*`、`ST_D_*` 等）
  - 技能、被动、状态效果与战斗提示
  - 物品与装备描述、教程卡片、加载提示、任务文本
- 统一了以下术语与格式（均计入 451 条内）：
  - `Can Break`：由「有可能击破」改为「**可以击破**」（can 表能力，不是概率），共 45 处
  - Stance：统一为「站姿」
  - weakening strike：统一为「削弱攻击」，与「击破」机制区分
  - Dark element：统一为「暗影」
  - Expedition Flag：统一为「远征旗」
  - Burn 家族：统一为状态本名「着火」
  - 护盾、连续攻击等术语，以及引号、句末标点格式等

### 修正的部分官方硬伤实例

以下改动均经英文、法文、德文、日文与繁体中文多语言交叉验证：

| 英文 | 原简体 | 修订后 | 说明 |
|---|---|---|---|
| Axon | 车由泰坦 | **轴突泰坦** | 「轴」被错误拆成「车+由」，共 42 条 |
| Catapult Sakapatate | 巫法土豆偶 | **石弩土豆偶** | 其余语言均为「石弩/投石机」 |
| Sabotage | 锐不可当 | **蓄意破坏** | 语义完全不符 |
| Critical Vulnerability | 虚弱暴击 | **破防暴击** | 与其自身描述「攻击破防的敌方」一致 |

### 刻意未改的内容

- 所有专有名词、人名、地名、组织名与机制术语，如抹煞（Gommage）、绘母（Paintress）、源色（Chroma）、符纹（Pictos）、灵光（Lumina）等。
- 菜单、系统 UI、按钮、设置项与键位名称。
- 意思大致正确、仅属个人风格的句子——不做单纯润色。

完整的逐条对照（英文 / 原译 / 新译 / 理由）见 [改动清单.md](改动清单.md)。

## 安装

1. 找到游戏根目录：
   Steam 库 → 右键《光与影：33号远征队》→ 管理 → 浏览本地文件。
2. 将仓库中的 `Sandfall` 文件夹放到游戏根目录下，最终形成：

   ```
   <Steam>\steamapps\common\Expedition 33\Sandfall\Content\Paks\pakchunk9999-Windows.pak
   ```

   也可以直接下载 [Releases 页面](https://github.com/cl9575/E33-zh-Hans-Text-Fix/releases) 里的压缩包
   （`Expedition33-zh-Hans-TextMod-v1.0.zip`），解压到 `Expedition 33\` 根目录并合并同名文件夹即可。

3. 进入游戏，将语言设置为「**简体中文**」。

### 注意

- 必须放在 `Sandfall\Content\Paks\` **根目录**，与 `pakchunk0-Windows.pak` 同级。
- 请不要修改文件名 `pakchunk9999-Windows.pak`。

## 卸载

删除 `Sandfall\Content\Paks\pakchunk9999-Windows.pak` 即可。原版文件未被改动，也不影响存档。

## 验证是否生效

1. 序章出发场景中，艾玛（Emma）的台词应为「**33号远征队。**」（原版误作「明日将至。」）。
2. 第二章寻找 Axon 相关剧情中，字幕应为「**轴突泰坦**」（原版为不通顺的「车由泰坦」）。

任一处符合，即说明 Mod 已生效。
